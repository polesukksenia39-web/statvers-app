Справочник

Краткие объяснения основных статистических методов и понятий.

Среднее значение

Сумма всех наблюдений, разделённая на их количество. Используется для количественных данных при отсутствии выраженных выбросов.

Медиана

Центральное значение упорядоченного ряда. Менее чувствительна к выбросам, чем среднее.

Стандартное отклонение

Показывает степень разброса количественных значений относительно среднего.

p-значение

Используется для оценки статистической значимости наблюдаемого результата при заданной статистической модели.

Доверительный интервал

Интервал неопределённости оценки, рассчитанный выбранным статистическим методом.
